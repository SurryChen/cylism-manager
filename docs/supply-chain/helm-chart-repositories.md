# Helm Chart 仓库

## 用途与边界

Helm Chart 仓库页面管理集群可用的 Chart 来源，供系统组件或受控安装流程使用。它不等于应用上线模板，也不负责管理 Chart 内部所有资源。

## 进入位置

进入“集群”，在 Chart 仓库标签页管理来源。

## 准备条件

准备仓库 URL、必要认证信息及组织认可的 Chart 版本策略。

## 核心操作

1. 添加 Chart 仓库并保存地址与认证配置。
2. 刷新索引，确认仓库可访问且 Chart 列表可读取。
3. 在系统组件或安装流程中选择明确的 Chart 与版本。
4. 更新来源或凭据后重新同步索引并记录变更原因。

## 状态与风险

仓库可访问不代表某个 Chart 兼容当前 Kubernetes 版本。不要使用未固定版本的 Chart 执行生产升级；删除来源前先确认没有待执行的组件安装依赖。
