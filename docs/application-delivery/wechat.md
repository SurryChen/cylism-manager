# 微信运营数据和推广码

1. 确认项目已有「微信小程序」或「微信小游戏」发行渠道。
2. 在微信公众平台的「开发管理 → 开发设置」获取该小程序或小游戏自己的 AppID 和 AppSecret。
3. 在 Manager 打开「项目 → 发行 → 微信接入」，选择渠道并保存 AppID 和 AppSecret。已有渠道填写了应用标识时，AppID 需与应用标识一致。AppSecret 在服务端加密保存，更新连接时留空会沿用已保存的值。

## 运营数据

进入项目「总览」，可查看活跃用户、新增用户和访问次数的 7 天或 30 天趋势。小游戏还支持分享、次日留存和广告分成后收入，具体数据取决于应用已开通的能力和微信返回的指标。

图表使用微信按日汇总的数据，显示数据截至日期和最近查询时间。点击刷新可查询微信已产出的数据。后台每 6 小时补查近 7 天，首次查询 30 天历史可能分多次补齐。微信尚未出数的日期在图上留空。

## 推广码

回到「微信接入」，填写场景值，例如 `poster-01`，生成并下载线上推广码。

断开连接会清除该渠道在 Manager 的凭据和运营数据缓存。历史版本与发行记录继续保留。后续可以在微信后台发布后，通过项目里的「版本」和「发行」登记正式版本。
