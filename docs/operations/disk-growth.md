# 磁盘增长

## 用途与边界

磁盘增长诊断按增长量列出节点挂载点和 PVC，帮助定位容量异常来源。它展示趋势，不会自动清理文件或扩容卷。

## 进入位置

进入“监控”，打开磁盘增长工作区。

## 准备条件

指标采集需正常；选择能覆盖异常发生时间的窗口。

## 核心操作

1. 选择最近 1 小时、6 小时、24 小时或更长时间范围。
2. 查看增长最多的节点挂载点，再检查关联目录或服务。
3. 查看 PVC 增长与挂载 Pod，回到应用或存储页面核对写入来源。
4. 在确认业务影响、备份和回退方案后，再执行清理或扩容。

## 状态与风险

无增长结果可能是时间范围不合适或指标缺失。不要仅依据增长量删除数据；节点磁盘与 PVC 的增长要分别处理，错误清理可能导致应用损坏。
