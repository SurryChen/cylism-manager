# 数据库终端与云监控

在「数据库 → 已有实例」打开实例详情。概览保留实例地址和常用操作；网关诊断、应用连接、复制关系分别在对应 Tab 中查看。

## 登录命令行

点击「登录终端」，选择平台已保存的管理账号或业务账号，再选择可以访问实例的执行集群和节点。私网网关实例使用网关所在集群，独立 MySQL 使用实例所在集群。

平台在所选节点创建临时 MySQL 客户端，使用 TLS 连接数据库。数据库密码不返回浏览器，也不写入客户端 Job 配置或启动参数。终端使用所选账号的实际权限，执行 SQL 前请核对实例和账号。

会话最长 30 分钟；关闭、断开或到期后清理临时客户端。点击重新连接会创建新会话。首次使用需要节点能够拉取官方 `mysql:8.0.44` 镜像。

## 阿里云 RDS 资源监控

在实例的「资源监控」Tab 点击「关联云监控」，选择已有阿里云连接，填写地域与 RDS 实例 ID。数据库账号用于 SQL 访问，阿里云连接用于云 API，两者互不替代。

所选云连接需要 `rds:DescribeDBInstancePerformance` 只读权限。页面展示云端 CPU、内存、空间、连接数以及 QPS/TPS，可选择最近 1、6 或 24 小时。没有返回的数据不会显示为零；权限或配置错误通过错误弹窗说明。

数据库可用状态与网关节点探测结果分别展示。部分节点探测失败时可查看诊断，应根据实际使用数据库的节点处理，不必扩大网关访问名单。

## 独立只读从库

「创建独立 MySQL」与「建立复制」是两个独立操作。先选择节点、镜像、资源与存储，等待 MySQL 就绪，再从源实例发起复制初始化。已有业务数据或已有复制通道的目标不能直接覆盖。

RDS 作为主库、独立 MySQL 作为从库时，复制账号应仅具有必要复制权限并要求 TLS。复制健康必须同时确认接收线程、应用线程、错误状态与 GTID 追平；只读从库不会自动代替 RDS 接收业务写入。

## 发现已有复制

在实例详情的「复制关系」中点击「发现已有复制」，选择实际的源、从实例及执行节点，创建后台任务。平台读取已有通道，并将通道中的源 UUID 与所选源实例核对；核对后登记关系和本次检查状态。此操作不初始化数据、不创建复制账号，也不修改正在运行的通道。多通道或源身份不匹配时拒绝登记，已有冲突关系不会被覆盖。

登记成功后可查看接收线程、执行线程、延迟与只读状态；这些是最近检查的结果，点击「检查复制」可更新。升级前失败的发现任务需要先终止释放资源锁，再重新创建。

## 识别已有应用连接

打开实例详情的「应用连接」，平台合并已有绑定和上线模板中的连接信息，展示应用、模板、数据库、账号及配置来源。环境变量支持 MySQL URL、Go TCP DSN，以及 MYSQL / DB / DATABASE 分组字段；挂载的 YAML、JSON、dotenv 文件也参与识别，包括模板明确引用的 ConfigMap / Secret 文件键。实例地址与私网网关地址均可匹配，Service 地址按集群区分。

「配置识别」仅表示模板中引用该实例，不代表应用当前有活动连接，也不会自动创建绑定或改写配置。点击应用名称进入部署配置更新；修改后可刷新识别结果。密码和完整连接串不会返回浏览器。读取失败会提示不完整原因；不支持的格式、未解析的变量和未登记的地址别名可能无法识别，空列表不代表无人使用。
