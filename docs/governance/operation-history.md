# 操作历史

## 用途与边界

操作历史展示平台发起的管理任务及其执行结果，适合确认安装、发布、资源变更或维护操作的进度。它不等同于审计日志的全部合规视图。

## 进入位置

进入“操作历史”页面，按时间、状态或目标资源查找。

## 准备条件

记录发起操作的时间、对象和预期结果，以便在历史中准确定位。

## 核心操作

1. 查看进行中、成功和失败任务，打开失败项读取原因。
2. 对照资源当前状态，判断任务是否仍在收敛。
3. 将重要操作与发布、告警和审计事件关联记录。
4. 失败后先修正前置条件，再创建新的操作，而非假设旧任务会自动重试。

## 状态与风险

任务成功表示平台请求已完成，不一定代表业务完全恢复。并发执行相互影响的操作可能产生竞态，应等待关键任务结束后再进行下一步。
