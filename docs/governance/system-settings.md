# 系统设置

## 用途与边界

系统设置用于维护平台级安全与访问、平台入口、发布与更新等配置。它们会影响多个管理功能，不是单个项目或应用的配置入口。

## 进入位置

进入“系统设置”，在安全与访问、平台入口、发布与更新标签页间切换。

## 准备条件

变更前记录当前配置，并准备管理员权限、维护窗口和回退方案。涉及入口地址或安全设置时，先确认现有管理会话不会被中断。

## 核心操作

1. 检查安全与访问配置是否符合组织要求。
2. 更新平台入口或发布策略时，逐项保存并验证。
3. 涉及平台更新时先确认版本兼容性、备份和相关组件状态。
4. 重大变更后查看操作历史和审计日志。

## 状态与风险

平台级设置可能影响所有用户和集群。不要在无法回退时直接修改入口、安全或升级策略；应先在低风险环境验证，再安排生产变更。
