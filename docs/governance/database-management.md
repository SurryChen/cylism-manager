# 数据库管理

## 用途与边界

数据库管理支持 Operator 集群、平台部署的独立 MySQL 和外部 MySQL / RDS。RDS 作为外部实例接入，不加入 Oracle InnoDBCluster。部署、迁移、建立复制和切换应用连接分别执行；登记实例不会自动创建备库。

## 进入位置

进入“云服务 → 数据库”。“MySQL 集群”保留 Operator 集群；“已有实例”列出外部实例和平台独立 MySQL。点击“查看与配置”，分别查看概览、网络、应用和复制关系。列表只展示摘要，检查详情放在弹窗中。

## 准备条件

确认数据库类型、所属应用、数据敏感级别和维护窗口；任何结构变更、导入或恢复前先完成可验证备份。

## 核心操作

| 能力 | 使用方式 | 结果 |
| --- | --- | --- |
| 接入已有 MySQL | 登记地址；按需配置私网网关和现有管理凭据 | 统一查看 RDS 或外部实例，业务账号可后配 |
| 部署独立 MySQL | 选择集群、节点、镜像、资源上限与数据卷 | 单实例 StatefulSet，默认 1 核 / 1 GiB，启用 GTID/binlog 和对应内存参数 |
| 检查实例 | 选择实例及一个执行节点 | 读取版本、业务库清单、只读状态；不要求全节点检查通过 |
| 迁移数据 | 选择源、目标和业务数据库，确认源库停写 | 导出一致性快照、导入并比较对象清单；不迁移系统账号 |
| 建立复制 | 选择源库和全新独立 MySQL，提供预先创建的复制账号 | 用快照初始化目标后建立 GTID 异步复制，目标持久保持只读 |
| 检查 / 解除复制 | 从实际复制关系发起 | 检查线程与延迟，或移除指定通道并保留只读与数据 |
| 切换应用连接 | 选择已绑定模板并填写各自的目标业务连接 | 验证连接后原子更新所选模板；到应用页面发布才会改变运行中的应用 |

管理凭据用于检查、迁移和复制；业务连接保存已存在的数据库和账号，不在 MySQL 中创建账号。不同模板可分别切换到 RDS 上不同的业务库和账号。密码加密保存，页面和任务日志不回显。

### 将现有集群迁到 RDS，再创建独立从库

1. 登记 RDS，配置可用网络及管理凭据，在实际执行位置检查连接。
2. 准备 RDS 所需参数和业务账号，停止待迁移源库的写入并保持停写。
3. 单独发起迁移任务，完成后核验数据；选择应用模板，切换业务连接并发布、验证。
4. 如需从库，再在指定节点部署独立空 MySQL。版本应与 RDS 相同系列。
5. 在 RDS 准备复制账号、网络权限和 binlog 保留策略，单独发起建立复制任务。

该流程不提供自动故障切换；异步从库也不能替代独立备份。

### 后台任务与恢复

任务页展示阶段、快照大小、执行位置和持久日志。任务没有全局执行时限，平台重启后继续观察原有 Kubernetes Job。暂停在当前阶段完成后生效；继续从下一个检查点开始。

失败或暂停时保留资源锁，防止再次导入或改写相同目标。检查失败原因后可以终止；终止等待执行 Pod 退出，并核对可能已创建的复制通道后释放锁。已经建立的复制会保留，可单独解除。终止部署任务也保留已创建的 MySQL。切换模板若已提交，终止不会回滚模板。

任务结束后自动清理执行 Job 和凭据 Secret；实例、已导入数据和快照 PVC 保留。快照确认不再需要后，可从存储页面清理。

### 当前兼容范围

迁移和复制限制为两端相同的 MySQL 8.0 或 8.4 系列；迁移拒绝覆盖目标同名库，目标必须可写且开启 `local_infile`。复制要求源库开启 GTID/binlog，目标为没有业务库、GTID 历史、复制通道或应用绑定的平台独立 MySQL。数据库原生账号、权限、TLS 和网络策略仍需满足 MySQL Shell 与复制要求。

快照导入成功和对象清单一致不等于业务校验完成，应用切换前仍应核验关键数据、业务查询和授权。资源受限的执行 Job 默认上限为 1 核 / 1 GiB，大规模迁移应先验证工作集和快照卷容量。

## 状态与风险

实例就绪不保证业务数据正确。数据库删除、恢复、导入和参数变更都可能造成不可逆影响；凭据和连接串不得写入公开文档、截图或工单评论。
