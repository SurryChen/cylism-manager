# 数据库管理

## 用途与边界

数据库管理页面用于查看和维护平台支持的数据库运行时及其管理操作。它面向受控数据库资源，不替代数据库原生的高级运维、权限模型和业务备份策略。

## 进入位置

进入“数据库管理”页面，选择目标数据库实例。

## 准备条件

确认数据库类型、所属应用、数据敏感级别和维护窗口；任何结构变更、导入或恢复前先完成可验证备份。

## 核心操作

1. 查看实例状态、连接信息与关联运行资源。
2. 根据页面支持的能力执行创建、查看或维护操作。
3. 将应用变更与数据库操作分开安排，并在操作后验证连接和数据。
4. 遇到容量或性能问题，先检查 PVC、节点资源和应用访问量。

## 状态与风险

实例就绪不保证业务数据正确。数据库删除、恢复、导入和参数变更都可能造成不可逆影响；凭据和连接串不得写入公开文档、截图或工单评论。
