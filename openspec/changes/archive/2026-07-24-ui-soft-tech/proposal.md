## Why

当前 UI 使用内联压缩 CSS 变量，暗色主题勉强可用但亮色模式多处硬编码颜色导致显示异常。组件风格不统一（有的弹窗有阴影、有的没有，亮色模式下 tab-active 文字不可见）。滚动条占用布局空间导致页面切换时"抽搐"。整体缺乏现代化 SaaS 工具的精致感。

## What Changes

- 采用 **Soft Tech** 设计语言：暖灰底、紫蓝强调色、大圆角、微妙阴影
- Design Tokens 完整重定义（含亮/暗两套完整变量）
- 所有组件统一视觉（卡片、按钮、模态、表格、徽章、表单）
- 滚动条改为 overlay 模式，不占布局空间
- 亮色主题全页面适配（移除硬编码颜色）
- 微交互动效（hover 过渡、focus ring、modal 进出）
- 移动端响应式完善
