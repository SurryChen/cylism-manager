## Why

审计日志页面当前将所有筛选条件平铺在一块高面板中，主次不分；动作和资源选项也没有覆盖类型化审计事件，用户选择后容易得到空结果。需要将高频筛选收口到主栏，把低频条件放入弹层，并确保时间范围等条件真正传递到服务端。

## What Changes

- 将关键字、结果、资源作为紧凑的主筛选栏，来源、动作、操作者、目标和时间范围放入筛选弹层。
- 展示已启用筛选条件，可单独移除或一键重置；移动端保持可用。
- 对齐实际审计资源和语义动作选项，避免使用不存在的筛选值。
- 审计列表 API 支持按创建时间起止范围查询。

## Impact

- 影响 `web/src/views/AuditLogs.vue` 及其测试。
- 影响审计 API 查询 DTO、repository 查询和相关后端测试。
- 不改变已有筛选参数和审计数据结构；新增时间参数向后兼容。
