## Decisions

### 1. 备份先于迁移

每个导入任务在源节点创建 `tar.gz` 归档和文件清单校验，归档默认保存到受限的本地备份根目录。任务未验证前禁止删除备份；验证完成后由用户显式删除。

### 2. 同节点与跨节点分别执行

同节点任务使用受控迁移 Job 挂载源 hostPath 与目标 PVC。本地 PVC 已绑定其他节点时，使用平台 SSH 从源节点发送 tar 流到目标节点接收 Job；PVC 始终只挂载到其绑定节点。

### 3. 停止写入并恢复应用

任务可关联一个应用和上线模板。开始前记录副本数并缩容至零，迁移与校验成功后写入 PVC 挂载并恢复副本；失败时保持应用停用并显示可恢复步骤。

### 4. 受限源与备份目录

拒绝根目录和系统虚拟目录，路径必须是经过 SSH 校验的绝对目录。备份目录由平台配置的允许根目录派生，避免界面成为任意文件读取接口。

## Risks

- 跨节点网络中断：保留源备份与任务状态，支持重新执行，不覆盖已验证数据。
- 目标 PVC 数据覆盖：默认拒绝非空 PVC；覆盖需要二次确认并保留目标目录备份。
- 本地备份随节点损坏丢失：界面标明其仅用于迁移回退，不承诺灾难恢复。
