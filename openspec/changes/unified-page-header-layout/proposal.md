# 统一页面标题区规范

## Why

前端当前同时存在 `PageHeader`、`SectionTabsHeader`、各页面自定义 `.page-header` 和 Hub 标题实现。它们在标题字号、标题区高度、分隔线位置、操作区对齐和移动端行为上不一致，导致同一侧栏下的页面切换时视觉跳动，也容易继续产生重复的页面级标题层。

## What Changes

- 建立统一的页面级标题区分类和组件使用规范。
- `SectionTabsHeader` 作为工作区页面的统一标题组件；没有真实子分类的页面使用单 Tab，存在真实子分类的页面使用多 Tab。
- `PageHeader` 仅用于详情、编辑、终端和其他没有工作区 Tab 语义的页面。
- 收敛现有 Hub 和自定义页面标题的重复 CSS，迁移到共享组件或保留为明确的内容级标题。
- 统一桌面端标题区高度、标题字号、横线/激活态位置、操作区对齐和移动端换行规则。
- 保留现有路由、侧栏层级、API 请求、业务状态和页面内交互。

## Impact

- 影响 `web/src/components/PageHeader.vue`、`SectionTabsHeader.vue` 及其样式 token。
- 影响工作区型页面：应用工作台、服务器、集群、网络、资源、监控、运行时、记录与系统等。
- 影响相关页面测试和组件测试；不改变后端接口或路由地址。
