## Why

公开文档当前主要按安装、配置和运维流程组织，无法反映 Cylism Manager 已有的应用交付、供应链、平台资源、可观测性、治理和自动化能力。用户需要以产品功能域定位操作说明，同时保留部署、配置、安全和开发资料作为辅助信息。

## What Changes

- 按“概览、应用交付、制品与供应链、资源与平台、可观测与运维、治理与系统、自动化助手”建立产品文档目录和 VitePress 导航。
- 为每个已有产品能力撰写面向操作员的中文说明，聚合 Kubernetes 资源、网络与证书、存储等紧密相关的子能力，避免产生无法扫描的超长侧栏。
- 保留既有快速开始、安装部署、配置参考、安全和开发贡献页面及其 URL，并将其作为辅助文档入口。
- 为需要产品界面的章节放置统一、可见、可替换的截图占位组件，声明建议的截图内容与资源文件名；不使用虚构截图。
- 将文档结构检查扩展为新目录、导航链接和截图占位契约检查。

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `public-documentation-site`: 公开文档的信息架构、产品内容导航、内容页面和截图占位规则变更。

## Non-Goals

- 不改变 Web 前端导航、Vue Router、后端 API 或任何产品功能。
- 不承诺尚未存在独立工作流的功能；身份权限、安全和自动化执行仅说明现有能力与边界。
- 不生成、采购或伪造产品截图；实际截图由后续人工替换占位组件。
- 不删除既有安装、配置、安全和贡献文档路径。

## Impact

- 文档：新增产品域目录、页面和截图占位组件；更新首页、VitePress 顶栏和侧栏。
- 质量检查：文档站检查脚本需要验证目录、导航和占位组件引用。
- 兼容性：既有公共页面 URL 和内部链接继续有效。
