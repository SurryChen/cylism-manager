## Navigation Model

基础设施保留一级导航。侧栏仅保留按管理对象划分的六个入口：服务器、集群、Kubernetes 资源、网络访问、存储和监控。

聚合入口按页面逐一优化。集群使用单层标题栏，标题右侧平铺节点、节点镜像源和 Chart 仓库。一级视图是同级的日常操作入口，不再使用配置弹窗或二层 Tab。服务器等无切换项的页面复用相同标题栏高度与底部细线，但不保留空白 Tab 区域。

聚合入口的层级如下：

- 集群：节点、节点镜像源、Chart 仓库。
- Kubernetes 资源：工作负载、服务、配置。
- 网络访问：路由、证书。

已有业务视图保持其数据请求和操作逻辑。聚合容器只处理页面标题、页内导航与当前视图选择，避免重复实现资源操作。

## Routing

聚合视图使用新的顶级路由和 `tab` 查询参数表示当前子视图：

- `/cluster?tab=nodes|registry-mirrors|chart-repositories`
- `/resources?tab=workloads|services|configs`
- `/network?tab=routes|certs`

原有的细分地址不再作为独立页面路由，而是重定向到上述新地址。证书签发过程属于证书详情，重定向到网络访问的证书视图。

## Interaction

选择页内 Tab 时更新查询参数，因此刷新、浏览器前进后退和直达链接都能保留当前视图。侧栏仅高亮聚合入口，桌面侧栏不再重复展示当前模块标记。

公共页面标题栏不渲染“当前工作区”等伪元素。无分栏页面的标题左对齐并可保留右侧操作按钮；聚合视图中的无操作子页不重复展示叶子标题。

服务器、存储卷和监控使用共享的无分栏标题栏，固定高度为 52px，包含一致的标题基线、右侧操作区和底部细线。标题栏不承载说明文字，以确保所有页面高度一致。聚合视图标题线与首个内容区之间必须保留固定间距，避免内容卡片与标题线视觉重叠。
