# 数据库独立能力 Demo

在 web 目录运行 `npm run dev -- --host 127.0.0.1`，打开 `/demos/database-migration/`。当前演示地址为 `http://127.0.0.1:5190/demos/database-migration/`。

独立 Vite 入口，复用正式组件、列表布局和 Design Tokens。仅使用内存中的示例记录，无 API 请求，不执行数据库命令。刷新页面会丢失演示状态。

页面保留「MySQL 集群 / 已有实例」双 Tab。长地址、连接配置、复制关系、任务记录在详情弹窗中展示。任务列表初始为空；未建立复制时不出现备库和计划拓扑。

独立能力：

1. **部署 MySQL**：选择独立 StatefulSet、服务器独立容器或 Operator InnoDBCluster，以及位置、版本、资源和存储。模拟完成后新增实例，不自动绑定主库。
2. **接入已有实例**：登记自建或托管 MySQL 的连接信息。Demo 不验证凭据。
3. **数据迁移**：选择两个已有实例和业务库范围，演示数据与兼容账号权限迁移，不创建备库或改变应用连接。
4. **建立复制**：选择主库与已有独立实例作为备库，演示检查、初始化和持续复制。完成后才显示复制关系。
5. **解除复制**：独立任务停止指定关系，保留实例及数据。
6. **切换应用连接**：选择目标实例和应用，审阅当前连接后单独执行。

可先在 RDS 详情打开「复制关系」，确认空状态，再部署独立实例、从 RDS 建立复制，查看关系和解除复制。迁移与应用连接切换可分别体验。每个任务有独立进度、日志、暂停和继续；关闭弹窗后继续模拟。同一实例或应用的活动任务互斥。

设计边界：

- 服务器独立 MySQL、迁移、复制均为待实施的产品能力，本 Demo 不表示后台已支持。
- Oracle Operator 继续管理其自己的 InnoDBCluster，RDS 作为外部实例统一纳管；不把 RDS 当作 Operator 集群成员。
- RDS 到自建实例的同步方式需核实版本、binlog/GTID、账号与网络，不能仅凭实例登记保证原生复制可用；必要时采用 DTS。
- Demo 迁移模拟全量复制，不等同于无停机迁移。线上持续写入场景须配置增量追平或维护窗口，然后独立切换应用。
- 账号权限、复制凭据、数据冲突、切换和回退保护需要正式实现。备库提升和主从切换尚未加入本 Demo。
